# Data Model

Entities: `categories`, `products`, `skus` (`wholesalePaise`/`moq`/`tiers` buyer-approved & admin only), `customers`, `orders`, `order_items`, `reservations` (`expiresAt` indexed), `webhook_events` (`eventId` PK), `shipping_rates`, `zones`, `coupons`, `quote_requests`, `email_log`, `audit_log`, `price_log`, `otp`.
