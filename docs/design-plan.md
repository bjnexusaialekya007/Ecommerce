# Design Plan

## 1. Surface Modes
- Persuade: Home hero & Wholesale landing.
- Operate: Shop, Product, Cart, Checkout, Order Status, Account, Admin.
- Read: About, FAQ, Policies (60-70 ch).

## 2. Memorable Detail
Paper-label pack chips showing live per-100 g unit price (`unitPricePer100gPaise`) alongside MRP strike and `You save ₹X`.

## 3. Three Dials (1-10)
Shop: VARIANCE 4, MOTION 3, DENSITY 4 | Admin: VARIANCE 2, MOTION 1, DENSITY 7 | Home Hero: VARIANCE 6, MOTION 4.

## 4. K7 Critique (Before / After / Why)
| Before | After | Why |
|---|---|---|
| Centred eyebrow hero | Left-aligned Fraunces H1 + 4:3 photo | Faster 5-second comprehension, removes template clutter |
| Icon-in-circle 3-card row | Numbered sequence list with 20 px icons | Matches ordering flow without SaaS template cards |
| Multi-page checkout | Single-page 3-step collapsible flow | Preserves draft on mobile |
| Desktop admin table | Master-detail >= 1024 px, stacked cards < 768 px | Usable on mid-range Android devices |
